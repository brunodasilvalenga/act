FEATURES
Everything you need, nothing you don't
act wraps AWS Session Manager in a single terminal UI, so you can reach EC2, ECS, and RDS without bastions, open ports, or SSH keys.
EC2 Connect
List and filter running EC2 instances, then start an SSM session in one step.
ECS Exec
Pick a cluster, service, and task, then exec straight into the running container.
Port Forwarding
Forward local ports through SSM, including to remote hosts like RDS behind a bastion.
ECS Logs
Auto-detects the right log group and tails CloudWatch logs without extra setup.
RDP over SSM
RDP into Windows instances through SSM and auto-launch your RDP client.
SSH over SSM
Real SSH via ProxyCommand, no open inbound ports, with SCP, rsync, and agent forwarding.
Run Command
Execute scripts or commands via SSM Run Command without opening a session.
Favorites & Environments
Save frequent targets and switch instantly between prod, staging, and other environments.
Doctor & Self-Upgrade
Verify local dependencies and upgrade the binary with a single command.
HOW IT WORKS
From API call to shell — in seconds
No bastion hosts. No open inbound ports. No SSH keys to distribute. Just the AWS APIs you already trust.
01
Discover
Runs live AWS API calls to list EC2 instances, ECS clusters & tasks, and RDS databases in your account.
02
Pick
An interactive TUI shows every target with real-time fuzzy filtering — no copy-pasting instance IDs ever again.
03
Connect
Executes the right action for you — an SSM session, a port-forward tunnel, ecs execute-command, or a live log tail.

Get started in under a minute
Install act with your favorite package manager. No AWS console tabs, no VPN client — just your terminal.
View on GitHub
Linux/MacOS
curl -sSfL https://raw.githubusercontent.com/brunodasilvalenga/act/main/install.sh | sh
Go install
go install github.com/brunodasilvalenga/act@latest
Windows PowerShell
irm https://raw.githubusercontent.com/brunodasilvalenga/act/main/install.ps1 | iex
Requires AWS CLI v2 and the Session Manager plugin installed.
